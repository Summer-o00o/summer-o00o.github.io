01 / ACCESSIBILITY + AI

Live demo

In-Browser Alt Text Generator

A browser-based accessibility tool that runs multimodal inference locally—generating useful alt text without sending images to a backend.

  • Generates descriptions with SmolVLM-256M-Instruct
  • Uses a SmolLM2 rewrite loop to produce shorter alt text
  • Exposes the initial output and rewrite passes for inspection
  • Runs on WebGPU with a WebAssembly fallback
  • TypeScript
  • SmolVLM
  • WebGPU
  • WASM

About me

A nontraditional path into engineering.

While working in a biomedical research lab, I started teaching myself programming to automate repetitive workflows and build tools for the people around me. What began with Python scripts and a Java desktop application grew into full-stack development, cloud infrastructure, AI, and graduate study in computer science.

I’m continuing to learn the same way I started: by building projects, experimenting with new technologies, and participating in hackathons.
